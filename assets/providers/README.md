# Provider logos

Shared SVG assets for the desktop app and marketing website. The app imports these files; the website build copies the catalogued files into its image assets. All logos are bundled locally.

Product names and logos identify the supported databases and belong to their respective owners. Their use does not imply endorsement. Geometry is preserved. Monochrome marks use a light variant on dark surfaces; no logo receives a background tile. The SQL Server asset is the scalable 2025 blue mark, rather than the older wireframe logo.
